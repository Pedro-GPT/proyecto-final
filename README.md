# Las dos puertas

Juego 3D para navegador: una pregunta, dos puertas y un ranking compartido.

- Jugar: https://pedro-gpt.github.io/proyecto-final/
- `index.html` necesita `preguntas.js` al lado. Recompilar: `npm install && npm run build`.
- `servidor/`: ranking compartido (Cloudflare Worker + D1). Pruebas: `npm test`; publicar: `npm run deploy`.
